This release improves PDF decoding and brings new Kyo PDF and pipeline capabilities to the repository.

- Cross-reference streams validate field widths, ranges, and entry counts before allocating tables. ASCII85 and ASCIIHex decoding enforce output limits as data is decoded.
- Kyo PDF bounds content parsing and writes trailers that match rewritten documents.
- Typed PDF pipelines support composition, branching, and parallel paths. The Paper Machine example lets you explore, validate, and assemble PDFs in a browser.
- The Scala.js source JAR preserves package paths, and CI verifies that an external Scala project can resolve and run the JVM artifact.

Maven Central artifacts: `io.github.adrielc:zio-pdf_3:0.3.0` and `io.github.adrielc:zio-pdf_sjs1_3:0.3.0`. The Kyo modules and Paper Machine are available from this source tag.
